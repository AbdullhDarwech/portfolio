# React Portfolio (Vite + Tailwind + Framer Motion)

## Quick start

1. Install dependencies
```bash
npm install
```

2. Run dev server
```bash
npm run dev
```

3. Open the URL shown by Vite (usually http://localhost:5173)

## Notes
- Edit files in `src/components` and `src/data/projects.js`.
- Place `resume.pdf` in `public/` if you want a downloadable resume.
